# Swagger local de BlueLife CRM

Esta carpeta contiene la documentación local de la API. No se publica como una ruta de Vercel.

Desde la carpeta `backend`, ejecuta:

```powershell
npm run docs
```

Después abre <http://127.0.0.1:4173> en el navegador. El comando vuelve a generar `openapi.json` antes de iniciar la página, por lo que refleja el código actual.
